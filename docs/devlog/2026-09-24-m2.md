## Rulings (decisions made on the owner's behalf; spec §12 lists the numbers)

1. **Detailed M2 spec written by the lead.** The spec's §4.3 and §5 left numbers and many behaviours
   open; §12 fixes them (health, gold, monster stats, stealth radii, prices, waves, boss). *Cost if
   wrong:* retuning after the owner's playtest.
2. **No fall damage, no hunger or thirst.** A children's game with triple jump; the spec already
   excludes hunger. *Cost if wrong:* less Minecraft-like tension.
3. **Sandbox has no hearts; summoned monsters only push.** "Monsters can be summoned for fun" — fun
   without being knocked out in a creative mode. *Cost if wrong:* none known.
4. **Cheat commands are off in Survivor** (`/tp /spawn /home /give /fly /ghost /time /summon /size`), like
   Minecraft survival. *Cost if wrong:* the owner wanted them everywhere (one list to change).
5. **Shield is passive** (best shield owned blocks a share of frontal damage; no button). Touch
   controls stay simple for children. *Cost if wrong:* less skill in fights.
6. **Pickaxe tiers gate the rare ores** (gold, diamond, crystal need iron), giving the trader's tools a
   reason. *Cost if wrong:* a small wall early on.
7. **M2 monsters: chaser (goblin) and jumper (slime).** The spec's universe 1 lists slimes and goblins;
   the other behaviours arrive with M3's universes. *Cost if wrong:* less variety in universe 1.
8. **The portal after the Golem unlocks universe 2 but leads nowhere until M3** ("opens in the next
   update"). Universes 2–4 are M3 content. *Cost if wrong:* none; M3 wires it.
9. **LAN gold is decided by the host and applied by each player's game** (trusted LAN until M4's
   server wallet), as §7.3 allows before M4. *Cost if wrong:* a modified client could fake gold in LAN.
10. **Parallel agents after a lead-built foundation**, with every new block/item id, HUD spot and
    atlas tile allocated up front (binary atlas conflicts cost time in M1b). *Cost if wrong:* agents
    wait for the foundation (~1 task).
11. **Sandbox monsters are gentle** (≤ 8, levels 1–2, hearts but no losses, a world ON/OFF setting),
    replacing ruling 3: the owner wants monsters to face in Sandbox too, and Sandbox stays a creative
    mode. *Cost if wrong:* the owner may want full Survivor-strength monsters in Sandbox.
12. **Secrets move from M3 into M2 for Green Meadows**; M3 adds them for its universes. The owner called
    them "most important". *Cost if wrong:* M2 grows by one large task.
13. **Bot friends are host-simulated companions with avatar bodies** (not network players), so they work
    solo and in LAN without extra peers. *Cost if wrong:* they cannot be controlled like real players.
14. **No drowning.** Swimming is freedom, not a danger, in a children's game. *Cost if wrong:* less
    Minecraft-like water tension.
15. **Fortnite-inspired, our own designs** (owner #22): mechanics (gliders, instant builds, launch pads,
    rarity colours, supply drops, emotes) are free to use; Epic's names, skins, characters and art are
    not. *Cost if wrong:* none — copying them would risk takedowns and store rejection.
16. **Cartoon blasters, never realistic guns**: store age ratings for a children's game (IARC) and the
    spec's "cartoon combat". *Cost if wrong:* less "Fortnite"; the owner may still want more realism.
17. **No item shop, battle pass or timed pressure** (§6 fair fun): all cosmetics are earned by playing.
    *Cost if wrong:* no revenue from cosmetics before a later, fair optional shop.
18. **Only the spear, mace and rarity colours join M2**; the rest of the action kit is M3 (§13), so M2
    ships sooner. *Cost if wrong:* the owner may want blasters sooner.
19. **Three small foundation pieces moved into the tasks that use them** (hearts HUD → Task 2, gold
    counter → Task 7, the `monsters` group in `CombatDirector` → Task 4), so eight agents could start at
    once (the owner: "and paralelize the work"). *Cost if wrong:* those agents touch `hud.gd` /
    `combat_director.gd` in parallel (small merges).
20. **Creature minds are small learned networks, not a text LLM** (owner #24, spec §12.17): a real
    language model costs hundreds of MB and about a second per answer on a phone, can't decide 10 times
    a second for 40 creatures, and free-generated words reaching children break the safety rules. Each
    creature gets senses, drives, memory and a tiny per-species network that learns from rewards, plus
    thought bubbles. *Cost if wrong:* if the owner wants creatures that talk freely, a curated
    server-side model for bot speech can come in M4 behind the same mind interface.
21. **Monsters learn only fair, signalled tactics** (never more damage, speed or sight; ease off after
    knock-outs; off in Cozy). *Cost if wrong:* monsters feel less "smart" to older children.

with the same seed. The underwater line gave it away: its fog colour `4e84b7` is exactly

the fog distance printed at the end of the check was already the water's. The tour's
`wait_until_true(…, 5 s)` had seen **one frame** and given up: the next frame took longer than the
whole budget on the crowded PC (a first-time shader variant or chunk meshing). The avatar check (sword in
the hand within 2 s of the style switch's long frame: `held_item 110`, the hand still showing item 0
because the player's `_process` ran before the weapon user's in that one frame) and the animals check
(`_go_surface` waits 5 s for `is_on_floor`) fail the same way. Not game bugs: measurement bugs.
- Fix: a wait gives up only after its time **and** `AcceptanceTour.MIN_WAIT_FRAMES` (10) frames
  (`test_a_wait_never_gives_up_before_its_minimum_frames`, RED on the assertion first). The Survivor tour
  inherits it.
- Ruling: a multi-second frame on first entering water under load 30 is not chased now; the performance
  row (autopilot, both styles) measures frame times on a quieter PC. Cost if wrong: a real stall on
  phones found later in M5's performance pass.
