## Rulings (decisions made on the owner's behalf)
1. **Detailed M3 spec written by the lead** (§14) from §5, §3a and §13; numbers are first values.
   *Cost if wrong:* retuning after the owner's playtests.
2. **Block atlas pages** instead of one bigger atlas: the 8 × 8 atlas is full after M2, and a 16 × 16
   realistic atlas would be 4096 px (too big for phones). Each universe/system gets its own page and
   material; a world only uses the pages it needs. *Cost if wrong:* one more draw call per page
   present in a chunk.
3. **Each Survivor universe is its own world** (slot `survivor_u<u>`), with a portal hub to go back.
   *Cost if wrong:* the owner may have imagined one endless world with universe regions.
4. **Smart blocks use one-step power** (a powered block powers what it touches), not redstone logic:
   children build contraptions without engineering. *Cost if wrong:* fewer clever machines.
5. **The Shorts Theater ships as "coming soon" until the owner creates the API accounts** (spec §11);
   its code path is tested with a bundled sample list. *Cost if wrong:* none (it can't work without keys).
