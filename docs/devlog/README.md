# Dev log

This is the project's chronological record: what the owner asked for and when, what was built (with
commit hashes), every decision made on the owner's behalf ("rulings", each with what it costs if it
is wrong), and every measurement (FPS, frame times, benchmark numbers). There is one file per work
period, for example `2026-09-23-m1b.md`. The `.superpowers/sdd/…/progress.md` ledgers are git-ignored
scratch. This folder is the durable record, so copy anything worth keeping here. Update the current
log at the end of every task.
