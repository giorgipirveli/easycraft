# Audio pass: effects, ambience and classical music (owner feedback #27, #31)
(Start from branch `worktree-agent-a633b61ec8e79c4c9` if it still exists: it has a WIP start.)

The owner (2026-09-24): "also consider to add sounds, effect sounds, musics and other sounds" and "musics i like, please also add some clasical musics like bethhoven, mozart and etc." This is M5 Task 2's audio part, pulled forward. Don't touch combat or the pause menu.

**Read first:** `CLAUDE.md`, `docs/DEVELOPMENT.md` (§8, audio sections), spec §5.15, §12.10, §15.2, `autoloads/audio.gd` and the Music code (`docs/devlog/parts/m2-task-11.md`), `world/ambience.gd`, `assets/CREDITS.md`, `tools/make_*_sfx.py`, `tools/make_music.py`, the universes' `music` fields (`world/universes/desert.gd`), owner rows #27/#31.

**Rules:** CC0 / public domain only, every file credited in `assets/CREDITS.md` (URL, author, licence) after checking the licence on the source page itself. Sources: Kenney audio packs (CC0), OpenGameArt CC0 entries, freesound CC0-only files; for classical music only **recordings released into the public domain** (Musopen's public-domain dedications, Wikimedia Commons recordings by US military bands, other files whose page states PD/CC0) — the compositions are PD, the recording must be too; otherwise render the piece yourself from a PD score with your own synthesizer (never a non-CC0 soundfont). OGG, mono effects, music ≤ ~2.5 MB each (loopable 1–3 min excerpts), APK growth ≤ ~30 MB (measure before/after). Pooled players, a cap on simultaneous sounds. TDD, full suite before commits, niced tests, no emulator/godot-mcp, never merge/push, commit trailer. Invoke `godot-prompter:audio-system` and `godot-optimization`. Notes: `docs/devlog/parts/audio-pass.md` (table: sound, file, source URL, licence; APK size before/after).

**Build:** (1) ≥ 8 classical pieces (Beethoven Für Elise / Ode to Joy / Moonlight 1st mvt, Mozart Eine kleine Nachtmusik / Rondo alla Turca / Symphony 40, Bach Air / Minuet in G, Grieg Morning Mood / In the Hall of the Mountain King (boss), Tchaikovsky Sugar Plum Fairy (Candy Kingdom), Vivaldi Spring, Satie Gymnopédie 1 (night)); a MUSIC setting Game / Classical / Mix (default Mix), the menu plays a gentle classical piece, an optional "Now playing" toast. (2) Effects: animal voices (idle calls within 20 blocks, hurt sounds), monster voices (slime, goblin; mummy/scorpion), footsteps by block (grass, dirt, stone, sand, wood, leaves, snow, wading), a splash and swim strokes, button clicks for every UI button, pickup pop, gold clink, a level-up/goal jingle hook (`Progress`/`LevelRules` exist now), a wave horn and boss roar if missing. (3) Ambience by place and time (birds by day, crickets at night, desert/peak wind, sea waves, cave drips), universes can name their own. (4) A SOUND EFFECTS volume beside music (profile, parsed defensively). Tests: settings round trips and old profiles, the music chooser (no piece twice in a row), footsteps by block, pooling (no growth after 500 sounds), ambience choice, a test that every audio file under `assets/` has a credits line.
