# M7 "Play in the Browser" Implementation Plan

> For agentic workers: runs on the Linux PC. Spec §20. Test-first where game code changes (GUT); the engine and browser
> glue are verified by exporting and loading the page in Chrome (this PC and the Android emulator's Chrome).

**Goal:** EasyCraft as an installable web app from our server, one build for every device, no store.

**State at the start (2026-09-27 23:10):** release 1.0.1; main `72d67a7`. Godot 4.7.2 web templates (incl. dlink) are
installed; they were built with Emscripten 4.0.20. Voxel Tools ships no web binary.

## Global constraints
- The owner's rules (CLAUDE.md): don't ask, decide and write rulings down; test-first; document in the project; never
  merge or push without the owner; English only; CC0 only; at most 3 agents; PC-wide suite slots.
- One codebase: no web branch. Web differences sit behind one platform rule, tested headless.
- Nothing loaded from third-party sites on the page.

## Tasks
1. **Toolchain and Voxel Tools for the browser.** emsdk 4.0.20 (`~/src/emsdk`), SCons (`~/src/sconsenv`), godot-cpp
   (`~/src/godot-cpp`, master of 2026-08-20), Voxel Tools source (`~/src/godot_voxel`, tag `v1.7x`). Build
   `platform=web target=template_release threads=yes`; add the `web` lines to `voxel.gdextension`. Script:
   `tools/build_voxel_web.sh`. Done when the `.wasm` side module exists and a spike export loads it in Chrome.
2. **"Web" export preset** (dlink templates, threads, PWA on, the page shell) and a local test server that sends the
   COOP/COEP headers (`tools/web_serve.py`). Done when the game reaches the menu in Chrome on this PC.
3. **Play in the browser:** Sandbox world loads, build, buddies, walking, saves; measure load time, download size and
   FPS on this PC's Chrome and the emulator's Chrome. Write the numbers into the dev log.
4. **Web-safe game code (test-first):** a platform rule for touch, LAN, quit, photos, low graphics on web phones; hide
   the LAN buttons; photo download; persistent storage request.
5. **Saves that survive a reload:** the voxel database and profile persist in browser storage (test: edit, reload,
   the edit is there).
6. **The installable app:** manifest, icons (the buddy), full screen, offline cache, our splash; English only.
7. **Hosting:** Caddy serves `/play/` with the right headers and types; `server/deploy` carries it; a small landing
   page ("Play now", "Install", the Android download).
8. **Phones in the browser:** tune until a phone browser plays acceptably (graphics defaults, view distance).
9. **Acceptance and hand-off:** Chrome and Firefox on this PC, Chrome on the emulator, the owner's iPhone Safari (on
   the owner's list); docs (DEVELOPMENT.md "Web" section, HANDOFF, RESUME-HERE, devlog).
